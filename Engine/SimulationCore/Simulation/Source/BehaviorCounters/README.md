# Runic::Simulation › Source/BehaviorCounters

Behavior counters: small per-player counters kept in fixed memory and flushed as one summary per player per interval through the service port.

- **Filled by:** SIM-7 (slice 39)
- **Status:** empty until SIM-7 (slice 39) starts

Private to `Runic::Simulation`: other modules reach this code only through the module's public headers.
