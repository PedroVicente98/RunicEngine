# Runic::GodotBridge › Source/Presenter

The presenter: RenderFrame instances created, moved and freed in the RenderingServer by RenderInstanceId, the presenter origin rebased about every 4 km, then meshes and MultiMesh, skinned instances, lights and fog, water and field grids.

- **Filled by:** GDB-3 (slice 5), GDB-5 (slice 22), GDB-6 (slice 23), GDB-7 (slice 25a), GDB-8 (slice 42a)
- **Status:** empty until GDB-3 (slice 5) starts

Private to `Runic::GodotBridge`: other modules reach this code only through the module's public headers. Files here use namespace `Runic::GodotBridge` (or `Runic::GodotBridge::Detail` for helpers several files of the module share); a helper used by one file sits in an unnamed namespace inside that file. Layout and rules: [the module's README](../../README.md).
