# Gameplay boundary

Future reusable, authoritative action-MMORPG frameworks belong here. Engine
definitions describe abilities, effects, items, quests, and characters; a game
supplies actual definitions, rules, balance, and lore. Spatial/action targeting
is the default philosophy, with explicit entity targets available where needed.
Local simulation events belong with their simulation code. No gameplay systems,
content loader, event bus, or speculative interfaces are implemented.
